# Security Policy

## Supported Versions

Security updates are provided only for the latest stable release of Shine Stacker. Previous releases are not supported and will not receive security updates.

| Version | Supported |
| ------- | --------- |
| Latest stable release | :white_check_mark: |
| All previous releases | :x: |

Users are encouraged to upgrade to the latest stable release to benefit from security fixes and other improvements.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Shine Stacker, please contact the maintainer through GitHub to arrange a suitable reporting channel.

Please include a description of the vulnerability, its potential impact, the steps needed to reproduce it, and any relevant technical details.

As a sole maintainer, I will review reports as soon as reasonably possible. I will acknowledge reports and provide updates as my availability allows, but I cannot guarantee a specific response time.

If a vulnerability is confirmed, I will assess its impact and, where appropriate, work on a fix for the latest stable release. Information about the vulnerability and its resolution may be published once a fix is available.

Not all reports will necessarily result in a security update. Reports may be declined if the issue is not considered a security vulnerability, cannot be reproduced, or does not warrant a security fix.
